# Mesa de Operações · Demonstração

Sala 3D com robôs de trading de cripto, **com robôs e dinheiro fictícios**. Abre em qualquer navegador, inclusive no celular, sem instalar nada.

A lógica da mesa (pasta `py/floor`, a mesma do sistema de verdade) roda dentro do navegador pelo Pyodide. Nenhum dado sai do aparelho de quem abre, e cada visita começa uma sala nova.

O que dá para fazer: ver os robôs operando, clicar num robô para ver os detalhes, contratar funcionários, mandar comprar e vender, pausar, demitir e simular um ganho.
